Cybersecurity & verification

Security is a continuous process, not a guarantee against every attack. This page is a static front end and cannot independently verify that the hosting environment, dependencies, or external services are free of vulnerabilities.

  • Use HTTPS and enable security headers at the hosting/CDN layer, including a tested Content-Security-Policy, Referrer-Policy, and X-Content-Type-Options.
  • Keep third-party scripts and dependencies to a minimum; update them and review changes before deployment.
  • Never place API secrets, passwords, private tokens, or sensitive personal data in client-side HTML or JavaScript.
  • If you add a backend or forms, validate input on the server, apply rate limits, protect against spam/CSRF where relevant, and restrict access to stored data.
  • Run a scan against the actual public domain after deployment and resolve findings; repeat scans after major changes.
